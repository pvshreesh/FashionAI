# Documentation

This folder contains all project documentation.

## Files

- **TECHNICAL_DOCUMENTATION.txt** - Complete technical and feature documentation. This is the master document that should be updated whenever we make changes to the app idea or implementation.

## Update Process

Every time we:
- Update app ideas or features
- Implement new functionality
- Change technical specifications
- Add new screens or user flows

We MUST update `TECHNICAL_DOCUMENTATION.txt` to reflect those changes. This document serves as the single source of truth for the entire project.
